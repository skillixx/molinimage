# 墨灵 AI 图片创作应用产品文档与规划

## 1. 产品概述

墨灵 AI 图片创作应用是面向墨灵平台用户的多模态图片创作工具，提供文生图、图生图、图片修复、图生文等能力。用户从墨灵平台进入应用后，可以围绕图片生成、图片编辑、图片修复和图片文案生产完成一站式创作，并按任务消耗墨灵积分。

本产品的核心价值不是单纯调用模型，而是把 AI 图片能力封装成可计费、可追踪、可复用、可运营的图片创作工作台。

## 2. 产品目标

### 2.1 用户目标

- 低门槛生成图片，不需要理解模型供应商、API 或提示词工程。
- 用上传图片继续创作，例如换风格、换背景、生成变体。
- 修复低质量图片，例如老照片修复、高清放大、去噪和色彩增强。
- 从图片生成可直接使用的标题、描述、标签、商品卖点和社媒文案。
- 能在作品历史中找回结果，并继续编辑、下载或复用参数。

### 2.2 平台目标

- 将 AI 图片能力作为墨灵平台应用上架，复用墨灵身份、权益、余额和计费体系。
- 所有模型调用统一走墨灵 AI 网关协议，应用不直连上游模型供应商。
- 建立任务、文件、计费、日志、作品历史的完整闭环。
- 支持后续运营风格模板、价格策略、模型开关和用户分层。

### 2.3 商业目标

- 第一阶段验证用户对图片生成和图片理解的使用频率。
- 通过积分消耗形成可持续收入模型。
- 通过作品历史和再次编辑提高复用率。
- 后续通过高清修复、批量处理、商业模板和企业品牌风格提高客单价。

## 3. 用户画像

### 3.1 内容创作者

需求：

- 快速生成社媒配图。
- 根据主题生成多种风格图片。
- 从图片生成标题、标签和发布文案。

关注点：

- 出图速度。
- 风格选择。
- 结果可下载和再次编辑。

### 3.2 电商/运营人员

需求：

- 上传产品图生成营销海报。
- 给商品图换背景、增强质感。
- 从商品图生成卖点文案。

关注点：

- 产品主体保持一致。
- 商业海报效果。
- 批量处理和成本可控。

### 3.3 普通用户

需求：

- 修复老照片。
- 提升模糊图片清晰度。
- 生成头像、壁纸或趣味图片。

关注点：

- 操作简单。
- 价格透明。
- 隐私安全。

### 3.4 企业/团队用户

需求：

- 统一品牌风格。
- 团队共享素材。
- 批量生成营销图片。

关注点：

- 模板沉淀。
- 权限和资产管理。
- 稳定性和审计。

## 4. 产品范围

### 4.1 第一阶段范围

- 余额展示和任务预计消耗。

- 图生文。
- 文件上传。

### 4.3 第三阶段范围

- 共享作品库。
- 更精细的局部编辑和画布工具。

## 5. 核心功能设计

### 5.1 AI 图片工作台

工作台是产品主入口，承载四类能力：

- 文生图。
- 图生图。
- 图片修复。
- 图生文。

用户在工作台内完成输入、参数选择、价格预估、任务提交、进度查看和结果操作。

### 5.2 文生图

用户输入提示词，选择风格、比例、质量、数量和模型，生成图片。

关键能力：

- 支持提示词输入。
- 支持风格模板快速套用。
- 支持图片比例选择。
- 支持图片数量选择。
- 展示预计积分。
- 生成后支持下载、收藏、再次编辑、复制参数。

验收标准：

- 用户能提交文生图任务。
- 余额不足时无法提交。
- 成功后结果进入作品历史。
- 失败时释放预占积分。

### 5.3 图生图

用户上传参考图并输入修改要求，生成新图。

关键能力：

- 上传一张或多张图片。
- 输入修改要求。
- 可选保持主体、换背景、换风格、生成变体。
- 生成结果保留输入图关联。

验收标准：

- 用户只能使用自己上传的图片作为输入。
- 图片格式、大小、分辨率不合规时给出中文提示。
- 成功后可继续以结果图再次编辑。

### 5.4 图片修复

图片修复是图生图的垂直包装，但在产品上作为一级功能展示。

修复类型：

- 老照片修复。
- 去噪增强。
- 模糊变清晰。
- 高清放大。
- 色彩增强。
- 局部瑕疵修复。

验收标准：

- 用户能选择修复类型。
- 高消耗修复任务有二次确认。
- 修复结果保留原图和修复类型记录。

### 5.5 图生文

用户上传图片后生成文字内容。

输出类型：

- 图片描述。
- 图片标题。
- 商品卖点。
- 社媒文案。
- SEO 标签。
- 提示词反推。

验收标准：

- 用户能上传图片并选择输出类型。
- 结果以文本面板展示。
- 支持复制、保存到历史、再次生成。

### 5.6 作品历史

用户可以查看所有历史任务和作品。

关键能力：

- 按类型筛选。
- 按时间排序。
- 查看任务状态。
- 预览图片或文本结果。
- 下载、收藏、删除、再次编辑。

验收标准：

- 用户不能查看他人的作品。
- 删除操作需要二次确认。
- 失败任务可以查看原因并重试。

### 5.7 价格与余额

用户在提交任务前应看到预计消耗。

关键能力：

- 顶部展示当前余额。
- 参数变化后实时更新预计积分。
- 余额不足时禁用提交按钮。
- 高消耗任务有确认提示。

验收标准：

- 价格展示与后端估算接口一致。
- 用户提交时后端再次校验余额和价格。
- 前端不自行计算最终扣费。

## 8. 产品规则

### 8.1 登录与权限

- 用户必须从墨灵平台入口进入应用。
- 应用后端负责校验 ticket 并创建 session。
- 所有任务、文件和作品必须绑定 `owner_user_id`。

### 8.2 模型规则

- 前端只展示应用后端返回的图片模型列表。
- 模型来自墨灵 AI 网关目录。
- 用户不可直接输入任意上游模型名。
- 后端提交任务前必须校验模型 active、可见、能力匹配。

### 8.3 文件规则

- 第一阶段支持 PNG、JPG、JPEG、WEBP。
- 文件大小和分辨率限制由后端配置。
- 文件存储使用 MinIO，后续迁移阿里云 OSS。
- 文件下载必须通过后端生成短期预签名 URL。

### 8.4 计费规则

- 提交前展示预计积分。
- 任务创建时预占积分。
- 成功后结算积分。
- 失败后释放积分。
- 结算异常进入待对账状态。
- AI 网关 usage 只做成本核算，不直接对用户二次扣费。

### 8.5 内容安全规则

- 禁止生成违法、暴力、色情、仇恨内容。
- 禁止证件、票据、印章等高风险伪造场景。
- 第一阶段不开放去水印、去遮挡能力。
- 命中风控时给出产品化中文提示。

## 10. 迭代规划

### 10.1 M1：基础闭环

目标：完成可上线的文生图和图生文闭环。

交付：

- 墨灵入口。
- AI 图片工作台基础版。
- 文生图。
- 图生文。
- 文件上传。
- 作品历史。
- 余额和预计积分。
- MinIO 存储。
- AI 网关模型目录读取。
- 计费预占、结算、释放。

验收：

- 用户可以完成一次文生图并下载结果。
- 用户可以上传图片生成文本。
- 余额不足不能发起任务。
- 失败任务不扣费。

### 10.2 M2：图生图与修复

目标：补齐图片编辑和修复能力。

交付：

- 图生图。
- 图片修复。
- 高清放大。
- 风格模板。
- 再次编辑。
- 任务详情。

验收：

- 用户可以上传参考图生成新图。
- 用户可以修复图片并保存结果。
- 修复任务支持二次确认和失败重试。

### 10.3 M3：运营配置

目标：让产品具备可运营能力。

交付：

- 价格配置。
- 模型开关。
- 模板管理。
- 任务对账。
- 用户限流。
- 消耗记录。

验收：

- 运营可调整不同任务价格。
- 管理端可关闭某个模型或模板。
- 待对账任务可重试处理。

### 10.4 M4：商业增强

目标：面向更高价值场景。

交付：

- 批量生成。
- 商品图处理。
- 商业海报工作流。
- 品牌模板。
- 团队空间。

验收：

- 用户可以批量处理商品图。
- 团队用户可以复用品牌模板。

## 11. 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| AI 网关图片能力标签不完整 | 前端无法正确筛选模型 | 在模型目录中补齐 capability，后端做兜底默认模型 |
| 任务耗时较长 | 用户等待焦虑 | 明确进度状态，支持离开后在历史查看 |
| 计费失败 | 用户资产状态不一致 | 预占、结算、释放、对账闭环 |
| 图片违规 | 合规风险 | 提示词审核、上传审核、结果抽检 |
| 存储迁移 | 文件链接失效 | 只保存 storage_key，通过 Storage Service 访问 |
| 用户不会写提示词 | 出图质量低 | 风格模板、提示词示例、提示词优化 |

## 12. 待确认事项

- 第一阶段图片上传大小限制。
- 第一阶段支持的图片分辨率上限。
- AI 网关图片模型的逻辑模型 code 和能力标签。
- 文生图、图生图、修复、图生文的正式积分价格。
- 作品保存周期。
- 是否需要在 MVP 中展示消耗明细。
- 图片修复是否允许局部修复，还是先仅支持整图修复。
