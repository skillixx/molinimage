# 墨灵 AI 图片创作应用前端 UI 设计文档

## 1. 设计目标

前端 UI 围绕“快速创作、清晰计费、结果可复用”设计。应用首屏直接进入 AI 图片工作台，不做营销型首页。用户进入后应立即知道自己可以做什么、需要上传或输入什么、会消耗多少积分、任务当前处于什么状态，以及生成结果还能继续做哪些操作。

设计原则：

- 工作台优先，减少引导和宣传内容。
- 功能入口清晰，文生图、图生图、图片修复、图生文并列展示。
- 参数配置紧凑但不拥挤，适合反复操作。
- 价格和余额始终可见。
- 结果区域突出图片和文本本身。
- 所有错误、空状态、加载状态都给出明确中文反馈。
- 前端只调用图片应用后端接口，不直接调用 AI 网关、MinIO 或墨灵内部接口。

## 3. 总体布局

### 3.1 桌面端布局

桌面端采用三栏工作台布局：

```text
顶部栏：应用名称 / 余额 / 作品 / 帮助
左侧栏：功能模式 / 最近作品
中间栏：输入内容 / 上传图片 / 参数配置 / 预计积分 / 提交按钮
右侧栏：结果预览 / 任务进度 / 操作按钮
```

建议宽度：

- 左侧栏：240px。
- 中间输入区：420px 到 520px。
- 右侧结果区：自适应，占主要空间。
- 内容最大宽度不强行限制，适合大屏预览图片。

### 3.2 平板端布局

平板端采用双栏布局：

```text
顶部栏
上方：功能模式横向切换
左侧：输入与参数
右侧：结果预览
下方：最近作品
```

### 3.3 移动端布局

移动端采用单列布局：

```text
顶部栏
功能模式横向滑动
输入区
参数区
预计消耗和提交按钮 sticky 底部
结果区
历史入口
```

移动端提交按钮固定在底部，但不能遮挡表单内容。

## 4. 页面设计

### 4.1 AI 图片工作台

#### 页面目标

让用户在一个页面内完成输入、参数选择、任务提交、进度查看和结果操作。

#### 页面结构

```text
AI 图片工作台
  顶部栏
  左侧功能栏
  中间创作面板
  右侧结果面板
```

#### 顶部栏

内容：

- 应用名称：AI 图片创作。
- 当前余额：显示“余额：xxx 积分”。
- 消耗记录入口。
- 我的作品入口。
- 帮助入口。

交互：

- 点击余额进入余额与消耗页。
- 余额不足时余额文案变为警示状态。
- 点击我的作品打开作品页或右侧抽屉。

#### 左侧功能栏

功能入口：

- 文生图。
- 图生图。
- 图片修复。
- 图生文。

每个入口包含：

- 图标。
- 名称。
- 一句话说明。
- 当前选中态。

最近作品：

- 展示最近 5 个成功任务。
- 失败任务不在这里展示，避免干扰创作，可在我的作品中查看。
- 点击最近作品后在右侧结果区打开预览。

#### 中间创作面板

公共区域：

- 模型选择。
- 风格模板。
- 预计消耗。
- 提交按钮。
- 参数重置。

模型选择：

- 数据来自 `GET /api/image/models`。
- 默认选择后端返回的默认模型。
- 仅展示当前功能可用的模型。
- 模型不可用时展示空状态：“当前暂无可用模型，请稍后再试。”

预计消耗：

- 展示“预计消耗 x 积分”。
- 参数变化后重新请求后端估算。
- 余额不足时提交按钮禁用，并显示“余额不足，无法生成”。

提交按钮：

- 文生图：生成图片。
- 图生图：生成新图。
- 图片修复：开始修复。
- 图生文：生成文案。

### 4.2 文生图模式

#### 表单字段

- 提示词输入框。
- 风格模板。
- 图片比例。
- 图片质量。
- 图片数量。
- 模型选择。
- 反向提示词，可折叠。

#### 提示词输入框

要求：

- 支持多行输入。
- 默认占位文案：“描述你想生成的图片，例如：一张高级感的科技产品海报。”
- 显示字数。
- 为空时不能提交。

辅助能力：

- 提示词示例。
- 一键优化提示词，可选。
- 清空按钮。

#### 参数控件

图片比例使用分段控件：

```text
1:1  4:3  3:4  16:9  9:16
```

质量使用单选卡片：

```text
普通
高清
超清
```

图片数量使用步进器：

```text
- 1 +
```

#### 结果区

生成中：

- 显示任务状态。
- 显示进度文本：“正在生成图片，预计需要几十秒。”
- 支持跳转到我的作品查看后台任务。

成功：

- 图片网格展示。
- 单图可放大预览。
- 操作按钮：下载、收藏、再次编辑、复制参数。

失败：

- 显示失败原因。
- 展示“重试”按钮。
- 说明“本次失败不会扣除积分”或“积分已释放”。

### 4.3 图生图模式

#### 表单字段

- 图片上传。
- 修改要求。
- 编辑模式。
- 风格模板。
- 图片比例。
- 图片质量。
- 模型选择。

#### 上传区

状态：

- 未上传：展示拖拽上传区域。
- 上传中：显示上传进度。
- 上传成功：显示缩略图、文件名、分辨率、大小。
- 上传失败：显示错误原因。

限制提示：

- 支持 PNG、JPG、JPEG、WEBP。
- 文件大小和分辨率以服务端配置为准。

编辑模式：

```text
保持主体
换背景
换风格
生成变体
```

#### 结果区

图生图结果需要并排保留原图入口：

```text
输入图缩略图
生成结果图
```

操作：

- 下载。
- 收藏。
- 继续以此图编辑。
- 查看原图。

### 4.4 图片修复模式

#### 表单字段

- 图片上传。
- 修复类型。
- 修复强度。
- 模型选择。
- 预计消耗。

修复类型：

```text
老照片修复
去噪增强
模糊变清晰
高清放大
色彩增强
局部瑕疵修复
```

第一阶段如果不做局部画布，局部瑕疵修复可置灰并标注“即将支持”。

修复强度：

```text
轻度
标准
强力
```

高清放大倍率：

```text
2x
4x
```

#### 二次确认

高消耗任务需要确认弹窗：

```text
本次高清修复预计消耗 6 积分，生成时间可能较长。是否继续？
```

按钮：

- 取消。
- 确认修复。

#### 结果区

支持前后对比：

- 左右对比。
- 滑杆对比，可在第二阶段实现。
- 下载修复图。
- 继续增强。

### 4.5 图生文模式

#### 表单字段

- 图片上传。
- 输出类型。
- 文案语气。
- 输出长度。
- 模型选择。

输出类型：

```text
图片描述
图片标题
商品卖点
社媒文案
SEO 标签
提示词反推
```

文案语气：

```text
自然
专业
营销
小红书风格
简洁
```

输出长度：

```text
短
中
长
```

#### 结果区

文本结果以卡片展示：

- 标题。
- 正文。
- 标签列表。
- 复制按钮。
- 重新生成。
- 保存到作品。

如果是提示词反推，结果区域展示：

- 中文提示词。
- 英文提示词，可选。
- 适用风格。
- 一键带入文生图。

## 8. 状态设计

### 8.1 空状态

工作台结果区：

```text
生成结果会显示在这里
```

作品历史：

```text
还没有作品，去创建第一张图片吧
```

模型列表为空：

```text
当前暂无可用图片模型，请稍后再试
```

### 8.2 加载状态

- 模型目录加载。
- 价格估算加载。
- 文件上传加载。
- 任务创建加载。
- 任务轮询加载。

加载状态需要显示在对应区域，不用全屏遮罩，避免打断用户。

### 8.3 错误状态

错误文案要求：

- 中文。
- 说明发生了什么。
- 告诉用户下一步能做什么。

示例：

```text
图片上传失败，请检查文件格式后重试。
余额不足，无法提交本次任务。
当前模型不可用，请切换其他模型。
生成失败，本次积分已释放。
```

### 8.4 禁用状态

禁用提交按钮的情况：

- 未登录或 session 失效。
- 必填输入为空。
- 未上传必要图片。
- 模型不可用。
- 价格估算失败。
- 余额不足。
- 内容安全预检查不通过。

## 9. 视觉风格

### 9.1 设计气质

产品应呈现“专业创作工具”的感觉，不做过度营销化布局。视觉风格保持清爽、稳定、效率优先。

关键词：

- 清晰。
- 专业。
- 高效。
- 可控。
- 轻量。

### 9.2 色彩建议

- 背景：浅灰白。
- 主色：墨灵品牌色，若无明确品牌色，可使用中性蓝或青色作为操作色。
- 警示：橙色。
- 错误：红色。
- 成功：绿色。
- 文字：深灰到黑色。

避免：

- 大面积渐变背景。
- 过强装饰元素。
- 把工作台做成营销 hero 页面。

### 9.3 图标建议

功能入口使用语义图标：

- 文生图：文字 + 图片。
- 图生图：图片转换。
- 图片修复：魔棒或修复。
- 图生文：图片 + 文档。
- 下载：下载图标。
- 收藏：星标。
- 再次编辑：编辑图标。
- 删除：删除图标。

## 13. 验收清单

- 用户进入应用后能看到工作台，而不是营销首页。
- 文生图和图生文入口清晰可见。
- 用户可以查看余额和预计消耗。
- 模型选择来自 `GET /api/image/models`。
- 余额不足时提交按钮禁用。
- 上传失败有明确中文错误。
- 任务生成中有进度状态。
- 成功结果支持下载、收藏、再次编辑或复制。
- 失败任务支持重试。
- 作品历史只展示当前用户作品。
- 移动端提交按钮不遮挡内容。
